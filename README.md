## FID-WIL Management System

## Overview:
The FID-WIL Management System is a web-based platform designed to connect students with companies offering Work Integrated Learning (WIL) opportunities. It streamlines the internship process by allowing students to create profiles, apply for placements, and track their progress, while companies can post vacancies, review applications, and provide feedback.

## My Role & Responsibilities:
I contributed to both the frontend and backend components of the system. My primary focus areas included:

Developing the Notification Module to alert students and companies about new placements or status updates.

Assisting with database design and integration between the user interface and MySQL backend.

Participating in code reviews, testing, and debugging to ensure a smooth user experience.

## Technologies Used:
 ▫️ **Java** 
 ▫️ **Spring Boot** 
 ▫️ **MySQL**
 ▫️ **HTML**
 ▫️ **CSS** 
 ▫️ **JavaScript**

Key Features:

-Student and Company Registration

-WIL Opportunity Posting and Application Management

-Automated Email Notifications

-Progress Tracking and Reporting

## Outcome & Learnings:
This project enhanced my understanding of full-stack development and teamwork in a collaborative environment. I learned how to design and implement backend services, manage relational databases, and ensure secure, efficient data handling. It also improved my ability to work under real project constraints and apply agile methodologies.
